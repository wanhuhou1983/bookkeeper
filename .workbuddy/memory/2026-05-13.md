### 踩坑
- python-jose 要求JWT的sub必须是字符串，不能用int
- SQLAlchemy配置表(account/category/channel/bank)的user_id必须用ForeignKey("users.id")才能建立relationship
- PG连接密码是 linhu50115 (不是默认的postgres)
- Windows下taskkill有时无法杀python进程，需要用PowerShell的Stop-Process
- Vant Weapp 需要安装 npm 依赖后手动复制 dist/ 到 miniprogram_npm/@vant/weapp/
- WXML 不支持 .find() 箭头函数等 JS 高级语法，需要用 WXS 或在 JS 层预计算
- 微信开发者工具需要在「详情→本地设置」勾选「不校验合法域名」才能访问 localhost
